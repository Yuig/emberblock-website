Нужно ли устанавливать Java?

Нет. Emberblock сам устанавливает подходящий Java Runtime по метаданным Mojang, указывать путь вручную не требуется.

Нужна ли лицензия Minecraft?

Вход через Microsoft проверяет право на Minecraft Java Edition. Офлайн-профиль предназначен только для локальной одиночной игры и не заменяет лицензию на официальных серверах.

Где хранятся моды?

В отдельном каталоге для каждой версии Minecraft и загрузчика, поэтому наборы модов не смешиваются.
