## 🇷🇺 О проекте EmberBlock (Русский)
**EmberBlock** — это современный лаунчер Minecraft с собственным зимним событием, уникальным новогодним модом и встроенными инструментами для игроков:
* **Skin Workshop** — полноценный 3D-редактор скинов прямо внутри лаунчера.
* **Кастомные 3D-аксессуары** — примерка шапок, шарфов и плащей прямо в окне программы.

## 🇬🇧 About EmberBlock Project (English)
**EmberBlock** is a modern Minecraft launcher featuring its own winter event, a unique holiday mod, and built-in tools for players:
* **Skin Workshop** — a fully-featured 3D skin editor built directly into the launcher.
* **Custom 3D Accessories** — try on hats, scarfs, and cloaks right in the launcher window.
